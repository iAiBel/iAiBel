## 📂 Projetos em Destaque

### 🏦 Predição de Inadimplência — Risco de Crédito (Lending Club)
> Python · XGBoost · SMOTE · CRISP-DM · 2025–2026

- Dataset real com **2,26M de empréstimos** (2007–2018); pipeline escalado para 1,3M registros após limpeza.
- 4 experimentos comparativos: baseline, SMOTE, VotingClassifier e XGBoost com `scale_pos_weight` dinâmico.
- Modelo final: **Recall 67%** e F1 0,43 na classe inadimplente — priorizando redução de falsos negativos.
- Modelo serializado (pickle) e validado em set independente — arquitetura pronta para deploy.
