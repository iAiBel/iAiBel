## 📂 Projetos em Destaque
 
### 🌡️ DynaHeat-BSB — Edge AI contra Ilhas de Calor Urbanas
> Python · Landsat 8/9 (TIRS) · Random Forest · Docker · 2026 · **Finalista ITU AI and Space Computing Challenge 2026**
 
- Cruza temperatura de superfície via satélite (NDVI/NDBI) com dados de IDH para achar onde calor extremo e vulnerabilidade social se sobrepõem em Brasília.
- Classificador Random Forest prioriza áreas para intervenção pública (ex.: arborização), alinhado ao ODS 11.
- Roda containerizado (Docker) como payload de Edge AI, só disparando alertas quando os limiares críticos são batidos — economia de banda e energia.
- Desenvolvido solo sob o nome **"Dyna Heat Lab"** 🔥
